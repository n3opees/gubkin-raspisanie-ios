# Расписание Губкина — iPhone

Виджет с расписанием РГУ нефти и газа им. Губкина для экрана «Домой» на iPhone. Показывает пары на сегодня, а после последней пары — на следующий учебный день. Подходит для любой группы. Работает через бесплатное приложение [Scriptable](https://apps.apple.com/app/scriptable/id1405459188).

Версия для Android (настоящее приложение с виджетом): [n3opees/gubkin-raspisanie](https://github.com/n3opees/gubkin-raspisanie).

## Установка

1. **Установи Scriptable** из App Store — бесплатно.
2. **Перенеси код в Scriptable.** Открой на iPhone ссылку на код: [gubkin-raspisanie.js](https://raw.githubusercontent.com/n3opees/gubkin-raspisanie-ios/main/gubkin-raspisanie.js), выдели весь текст и скопируй. В Scriptable нажми «+» вверху справа, вставь текст, нажми на название вверху и назови скрипт **Расписание**, затем **Done**.
   Если файл прислали в мессенджере: нажми на файл → «Поделиться» → «Сохранить в Файлы» → iCloud Drive → папка Scriptable. Скрипт сам появится в приложении.
3. **Запусти скрипт один раз в Scriptable.** Он попросит логин и пароль от личного кабинета (те же, что на lk.gubkin.ru) и код группы, например ГМ-24-11. Если появилось расписание — всё работает.
4. **Добавь виджет.** Зажми пустое место на экране → «Изменить» → «Добавить виджет» → Scriptable → **большой** размер (в него влезают все пары). Зажми виджет → «Изменить виджет» → в пункте Script выбери «Расписание».

Логин и пароль хранятся только на телефоне, в защищённом хранилище iOS (Keychain), и отправляются только на сайт личного кабинета. Сменить группу или логин — запусти скрипт в приложении, появится меню.

## Как работает

- Расписание берётся с lk.gubkin.ru через встроенный браузер Scriptable: прямые запросы из программ сервер университета тормозит, а браузер пускает.
- Скачиваются текущая и следующая неделя; виджет показывает их из памяти телефона, без интернета.
- Виджет перерисовывается после последней пары (переключается на следующий день) и в полночь. iOS может сделать это на несколько минут позже.
- Параллельные пары разных подгрупп показаны обе, с пометками **п/г 1** и **п/г 2**.

## Если что-то не так

- «Сервер расписания временно ограничил доступ» — подожди пару часов и не запускай скрипт много раз подряд.
- В приложении работает, а на экране «Домой» нет — запусти скрипт ещё раз в самом Scriptable, виджет подхватит свежее расписание.

## Для разработки

`node tools/sim-setup.js` — прогоняет скрипт в Node с подставными объектами Scriptable и поддельным сервером: первый запуск, неверный пароль, опечатка в группе, меню и смена группы.

Неофициальный виджет: сделан студентом для себя и одногруппников, университет к нему отношения не имеет.
